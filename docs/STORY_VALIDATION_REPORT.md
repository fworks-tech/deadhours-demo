## Validation Method

The Python validator (`validate_story.py`) checks:
1. **Uniqueness** — every checkpoint ID appears exactly once across all chapters
2. **Link integrity** — every `next` and choice target resolves to a real checkpoint ID
3. **Reachability** — BFS from `ch1_start`; flags any unreachable node
4. **Dead ends** — any non-ending checkpoint with no choices and no `next`
5. **Flag integrity** — every flag token referenced in conditions/set operations exists in `FlagsManager.gd` (73 flags defined)
6. **i18n coverage** — every `text`/`line`/`description`/`consequence_text` string in the story exists as a key in both `locale/en.csv` and `locale/pt_BR.csv`
